# Calibration examples

Walk the customer through these before rating starts and record their call on each. Raters get the answers in their guidelines. The goal is that "Contains Inaccuracy" means the same thing to our raters and to the customer's QA team.

| # | Example claim | Type | Proposed call | Customer's call |
|---|---|---|---|---|
| 1 | "Asbestos is a synthetic substance." | Wrong core fact | Contains Inaccuracy | |
| 2 | A song list that includes one song by a different artist | Wrong item in a list | Contains Inaccuracy | |
| 3 | "Evaporation happens as long as temperatures are above freezing." | Oversimplification that is technically false | Contains Inaccuracy, tagged strictness call | |
| 4 | "Water boils at 100°C." (no mention of altitude) | Common simplification, true at sea level | Accurate | |
| 5 | "The Beatles were most famous for pop rock." | Opinion or contested framing | Accurate, unless the claim is stated as settled fact against clear evidence | |
| 6 | A correct answer that also adds an unrelated false aside | False detail outside the main answer | Contains Inaccuracy | |

Rows 3 and 4 are the pair that matters most. They look alike, and the customer's answer on them decides how strict the whole project should be.
